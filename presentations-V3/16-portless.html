Named .localhost URLs

One-line change. Stable, semantic URLs forever.

Before
"dev": "next dev"
# http://localhost:3000
After
"dev": "portless myapp next dev"
# http://myapp.localhost:1355

Proxy :1355

  • Single entry point — "LESS" on a phone keypad

Random Port

  • App gets random port 4000–4999 via PORT env

Route by Name

  • myapp.localhost maps to the right backend

Technical Architecture

TypeScript 72%  ·  JavaScript 14%  ·  pnpm monorepo  ·  Turborepo

State Mgmt

  • Ports < 1024: /tmp/portless (shared)
  • Ports ≥ 1024: ~/.portless (user-scoped)

Process Mgmt

  • PID tracking, orphan detection, signal handling
  • Framework flags auto-injected via /bin/sh -c

Security

  • SHA-256 enforced for all certs — per-hostname SANs
