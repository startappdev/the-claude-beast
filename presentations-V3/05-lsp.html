What is LSP?

A standardized protocol between editors and language servers, created by Microsoft in 2016.

Before LSP

  • Every editor needed its own per-language implementation
  • Combinatorial explosion of N editors × M languages

After LSP

  • One server works in VS Code, Neovim, and Claude Code
  • Decoupled architecture — universal code intelligence

Why LSP Matters for AI Agents

Grep-based search vs. semantic understanding

Without LSP (grep)

  • Returns false positives — comments, strings, similar names
  • Burns tokens scanning raw files; can’t distinguish scope

With LSP (semantic)

  • Instant jump-to-definition with type info & docs inline
  • Auto-diagnostics after every edit — self-correcting errors

TypeScript LSP Setup

Four steps to semantic code intelligence

  • Enable the LSP Tool — export ENABLE_LSP_TOOL=1 or add to ~/.claude/settings.json
  • Install Language Server — npm install -g typescript-language-server typescript
  • Install the Plugin — /plugin install typescript-lsp@claude-plugins-official
  • Restart Claude Code — LSP requires a fresh session to initialize properly
Verify It Works Ask: “Go to the definition of the main function” — Working response cites file & line number. Not working: “I’m searching through the codebase…”

The Three Iron Laws of LSP

Non-negotiable rules for semantic code navigation

Law 1

  • No modifying unfamiliar code without go­To­Definition first
  • Understand the implementation before you change it

Law 2

  • No refactoring without find­References impact analysis
  • Assess the full scope of changes before you touch anything

Law 3

  • No claiming code works without running LSP diagnostics
  • Check for type errors after every modification

Setup & Configuration

Settings files, plugin config, and quick troubleshooting

Settings Locations

  • User ~/.claude/settings.json • Project .claude/settings.json
  • Local (private) .claude/settings.local.json

Plugin Config (.lsp.json)

  • “command” server binary • “transport” stdio or socket
  • “extensionToLanguage” file ext map • “restartOnCrash”

Quick Troubleshooting

  • “No LSP server available” — install plugin & restart
  • “Executable not found” — install binary; plugin silent — clear cache
