The Greploop

Autonomous review – fix – push — loops until 5/5 confidence and zero unaddressed comments

  • Trigger Review — invoke trigger_code_review on current PR
  • Wait for Completion — poll get_code_review until COMPLETED
  • Fetch Comments — retrieve all unaddressed Greptile comments
  • Fix & Commit — Claude Code applies fixes, commits and pushes to branch
  • Re-Review — trigger another review on updated code — repeat until done
The Vision Human expresses intent → Coding agent executes → Review agent validates → Loop until approved
