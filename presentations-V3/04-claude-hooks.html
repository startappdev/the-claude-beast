What Are Claude Code Hooks?

Shell commands, LLM prompts, or subagents that execute automatically at lifecycle events

Guaranteed

  • Not suggestions — fire every time conditions are met
  • Run with your full system permissions, no sandbox

I/O Protocol

  • JSON in via stdin, exit codes and JSON out via stdout
  • Analogous to Git hooks — but for AI development

Growing Fast

  • Originally 7 events (June 2025), now 14+ lifecycle events
  • Covers the full session from start to stop
The Key Idea Instead of hoping Claude remembers to lint, a PostToolUse hook runs Prettier automatically — every single time.

Three Hook Types

Speed, judgment, and verification — one type for each need

Command

  • Run a shell script — millisecond execution
  • Best for: formatting, linting, security checks

Prompt

  • Single-turn LLM decision — returns {ok: true/false}
  • Best for: complex decisions, semantic validation

Agent

  • Multi-turn subagent — up to 50 tool turns
  • Best for: multi-file checks, test suites, deployments

Matcher Patterns: Surgical Precision

Target exactly which tools or events fire your hook — matchers are case-sensitive

Exact / Pipe

  • "Bash" — exact tool name match
  • "Edit|Write" — pipe-separated alternatives

Wild­card / Args

  • "*" or "" — match everything
  • "Bash(npm test*)" — tool + argument pattern

MCP Regex

  • "mcp__github__.*" — all GitHub MCP tools
  • "mcp__.*__write.*" — cross-server write ops
Warning Matchers are case-sensitive: "bash" will NOT match the Bash tool. Always use PascalCase.

Guidance vs. Enforcement

CLAUDE.md is probabilistic — hooks are deterministic

CLAUDE.md

  • Behavioral guidance interpreted by the LLM
  • Can be forgotten, deprioritized, or lost after compaction

Hooks

  • Guaranteed execution — independent of model cooperation
  • Cannot be forgotten, deprioritized, or skipped

Decision Guide

  • “Prefer Bun over npm” → CLAUDE.md (preference)
  • “Never modify .env files” → PreToolUse hook (hard block)

Real-World Examples

Three production-ready hook patterns you can use today

Auto-Format

  • PostToolUse | Write|Edit — run Prettier on every save
  • Always exit 0 so it never blocks Claude accidentally

Block Danger

  • PreToolUse | Bash — block rm -rf, DROP TABLE, --force
  • Exit code 2 = blocked with feedback to Claude

Auto-Test

  • Stop — prevent Claude stopping until tests pass
  • Check stop_hook_active to avoid infinite loops
