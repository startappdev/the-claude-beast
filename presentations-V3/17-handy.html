What Is Handy?

Press a shortcut. Speak. Text appears. All local.

Core Concept

  • Global shortcut → speak → text inserted into active app
  • 100% on-device — no cloud, no internet required

Origin Story

  • Built by CJ Pais after breaking a finger
  • Needed one-handed operation without cloud lock-in

Philosophy

  • “The most fork­able STT app” — MIT licensed
  • Used by devs with dystonia worldwide
2/10
claude/code

Architecture

Tauri + Rust + React — ~12.6 MB installer, cross-platform

Pipeline

  • Shortcut → cpal mic → Silero VAD → resample
  • Whisper/Parakeet inference → LLM cleanup → paste

Core Libs

  • whisper-rs & transcription-rs for inference
  • vad-rs (Silero) + tauri-specta TS bindings

GPU Support

  • Metal (macOS), Vulkan (Windows/Linux)
  • Open­BLAS fallback — Rust 49% + TypeScript 49%

Post-Process & Custom­ization

LLM cleanup, replacement rules, and CLI scripting hooks

LLM Cleanup

  • Send transcript through local or remote LLM
  • Context vars: $currentApp, $shortPrevTranscript

Replace­ment Rules

  • Pattern find-and-replace, import/export via JSON
  • N-gram matching for multi-word corrections

CLI Control

  • --toggle-transcription & --cancel
  • SIGUSR1/SIGUSR2 for Sway, i3, KDE
